# FitLog

FitLog is a dark, responsive workout library and workout planning web application. Users can browse exercises, view workout details, save workouts for later, and build a plan for today's training.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- REST API
- Local Storage

## Features

- Responsive workout library for desktop, tablet, and mobile
- Workout detail pages with exercise information and instructions
- Add workouts to today's plan
- Save workouts for later
- Workout sorting by duration, calories, and rating
- Workout plan metrics for exercises, minutes, and calories
- Toast notifications for user actions
- Custom 404 page
- Loading states while workout data is being fetched

## API

FitLog uses workout data from the FitLog API.
